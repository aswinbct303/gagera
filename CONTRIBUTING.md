# Contributing

1. Branch from `main`.
2. Install with `npm install --legacy-peer-deps`.
3. Keep frontend changes accessible, responsive, and dependency-light.
4. Preserve the `/code` and `/settings/api` contracts unless documented.
5. Manually verify `/`, `/pair`, and `/settings` before opening a pull request.
6. Never commit credentials, session files, or generated runtime data.

Use focused commits and describe behavior changes in the pull request.
